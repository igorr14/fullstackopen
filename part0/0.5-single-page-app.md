# 0.5: Single page app diagram

Sequence diagram of the traffic when a user opens the single page app version of
the example app at `/exampleapp/spa`.

```mermaid
sequenceDiagram
    participant browser
    participant server

    browser ->> server: GET request /exampleapp/spa
    server -->> browser: sends HTML document

    Note right of browser: browser parses the HTML and finds the stylesheet link

    browser ->> server: GET request /exampleapp/main.css
    server -->> browser: sends main.css

    Note right of browser: browser keeps parsing and finds the script tag

    browser ->> server: GET request /exampleapp/spa.js
    server -->> browser: sends spa.js

    Note right of browser: browser executes spa.js, which sends an XMLHttpRequest

    browser ->> server: GET request /exampleapp/data.json
    server -->> browser: sends data.json with all the notes

    Note right of browser: browser runs the callback and renders the notes into the DOM
```
